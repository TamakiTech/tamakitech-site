Business Solutions

Business Software & Consulting is a division of Tamaki Technologies LLC. Engagements are fixed-fee projects in pension calculation automation, data reconciliation, and technical consulting.

Services

  • Pension calculation automation

    Calculation routines for pension administration, built so the inputs, the result, and the checks can be run again when the data changes. RetirementEngine.io is the product developed for this work. Custom automation is available as a fixed-fee project.

  • SQL and data reconciliation

    Compare data sources with SQL, match keys, and document the rows that do not agree. The work is for administrative files that need to line up before a calculation or a test is trusted. Source files stay with you. This site does not accept uploads.

  • Excel and Python automation

    Turn a recurring spreadsheet task into an Excel workbook or a Python script with a known input and a known output, so someone else on the team can run it.

  • Fixed-fee consulting

    Technical consulting scoped before the work starts: a deliverable, a timeline, and a fixed fee. The work draws on pension administration, automation, testing, and data management.

RetirementEngine.io

RetirementEngine.io is the flagship pension calculation platform of Tamaki Technologies LLC. It was developed by the company and remains a separate product and website.

The application is not embedded on tamakitech.com, and its code is not part of this site. Use the product at its own address.
